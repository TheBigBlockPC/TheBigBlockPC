## ✅ Finished projects

### 🦊 Foxy SDK
A prototype **Linux + Meta Quest VR stack** for building custom VR experiences without relying on SteamVR, ALVR, or competing OpenXR runtimes.

It includes:

- Quest Browser / WebXR tracking
- Python and native C++17 APIs
- OpenGL rendering
- POSIX shared-memory framebuffers
- CUDA IPC
- Hardware H.264 / NVENC encoding
- Custom VR hub worlds
- Controller, audio, and microphone support

Foxy is largely finished and was **vibecoded** as an experimental project.

→ [TheBigBlockPC/foxy](https://github.com/TheBigBlockPC/foxy)
